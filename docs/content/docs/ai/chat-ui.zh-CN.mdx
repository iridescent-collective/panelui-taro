`example/src/components/AIChatTemplate/index.tsx` 组合现有标题栏、历史记录、输入区、消息列表和语音界面，可运行路由是 `/showcases/ai/index`。

## 消息渲染

`hooks/use-chat-demo.ts` 保留预置回复驱动，并加入真实服务传输。每条消息记录生成模式，打开旧的本地会话不会把预置回复标成模型推理；真实请求只包含真实模式的消息。

`services/reduce-event.ts` 构造不可变的有序片段。相邻正文增量合并，同一工具 ID 的状态原位更新。`components/LiveBody` 使用 Message、Response 和 Task 渲染，再把来源汇总到回答下方。Response 已通过 CodeBlock 渲染围栏代码。只有收到推理内容才显示推理区；真实回复不会追加本地演示的计划、代码样例或来源。

## 交互生命周期

- 拒绝空消息和忙碌状态下的重复发送。
- 停止时先刷新待显示文本再中止请求，保留已生成内容。
- 重试替换最后一条助手回复，历史只发送到其前面的用户消息。
- 切换会话、新建会话、隐藏页面和卸载都会取消当前流。
- 使用生成序号忽略旧请求的延迟回调。
- 已完成消息保留对象引用，只给最新消息传入忙碌状态。

## 输入区与键盘

继续使用 PageLayout 页脚和 AIInput 键盘避让。MessageScroller 提供消息滚动和跳到最新消息控件。这是 Taro 适配，不使用 React Native FlatList，也不声称具有等价的原生列表回收能力。键盘遮挡和滚动行为仍需在开发者工具及手机上验证。

内置 brief 是固定样例，不是文件上传。真实模式勾选后，会把简短样例正文加入用户消息。语音转写先回填可编辑草稿，不自动发送。会话和草稿保存在内存，不做持久化。
