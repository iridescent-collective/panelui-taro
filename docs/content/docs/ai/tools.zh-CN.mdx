---
title: "工具调用"
description: "在服务端执行白名单工具，并展示真实调用状态。"
---

在真实模式中请求查找 PanelUI 的语音、工具或聊天文档。示例只开放一个服务端工具 `findPanelUIDocs`，参数 `topic` 的枚举值为 `chat-ui`、`tools` 和 `voice`。

工具查询固定的官方链接索引，不抓取网页，不进行网络搜索，不读取业务数据，也不执行模型生成的任意代码。来源区展示工具返回的链接，不生成虚构引用。

## 状态变化

| 流事件状态 | Task 状态 | 含义 |
| --- | --- | --- |
| `input-streaming` | pending | 工具名称或参数仍在到达 |
| `input-available` | running | 服务端开始校验并执行 |
| `output-available` | complete | 结果可展示，并回传给模型 |
| `output-error` | error | 工具名称或参数被拒绝 |

按供应商工具调用索引合并增量，客户端 ID 包含步骤编号。工具前后的正文顺序保持不变。服务端以 tool 消息回传结果，再请求下一轮模型生成，最多循环 5 步。未知工具不会执行，参数解析和校验后才会使用。

新增真实业务工具时，在自己的服务端定义 schema 与实现，在那里校验用户授权，并返回可序列化的展示结果。数据库访问、密钥和数据修改都不进入组件库。示例自定义流协议见[服务端路由](/docs/ai/api-route)。
