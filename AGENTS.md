# PanelUI Taro Agent Guide

- Before changing components, platform behavior, examples or docs, read [development contracts](.agents/references/development.md); select checks from [verification](.agents/references/verification.md).
- Preserve Native parts, APIs, themes, accessibility and provenance. Broader scope, business integration and publication require user authorization.
- Each library bug fix updates both troubleshooting guides in `docs/content/docs/`; source alignment, automated, simulator and device evidence remain separate.
